# sojourner
Modelo a escala del rover Sojourner de la Nasa en Marte

![alt text](https://github.com/felixstdp/sojourner/blob/main/sojourner.jpg)

Ficheros stl para imprimir

- assembly es el conjunto, sólo para verlo completo. NO IMPRIMR.
- wheel es la rueda, imprimir seis unidades.
- front bogie es el balancín frontal, imprimir una unidad tal cual y una reflejada a espejo.
- rear bogie (2 partes) es el balancín trasero, imprimir una unidad tal cual y una reflejada a espejo.
- stabilizing_bar es la barra de equilibrio, imprimir una unidad.
- rod es la biela, imprimir dos unidades.
- chassis_cage es el chasis-caja, imprimir una unidad.
- drill_stencil es la plantilla para taladrar, imprimir una unidad.
